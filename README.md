# 泰语单词学习网站

一个类似于百词斩的泰语单词学习网站，帮助用户通过图片联想、发音听辨、拼写练习等多种方式高效记忆泰语单词。

## 功能特点

- **单词卡片学习**：通过图片联想记忆泰语单词，卡片翻转显示详细释义和例句
- **发音练习**：播放标准发音，用户可跟读对比
- **记忆测试**：提供多种题型检验学习成果
- **学习进度追踪**：可视化展示已学单词量、掌握程度、学习时长等数据

## 技术栈

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (原生)
- Chart.js (数据可视化)

## 如何使用

1. 克隆仓库到本地
   ```bash
   git clone https://github.com/yourusername/thai-words-learning.git
   ```

2. 进入项目目录
   ```bash
   cd thai-words-learning
   ```

3. 打开 `index.html` 文件即可开始使用
